# Quick Start

## Access and Login

1. Open http://localhost:8000
2. Click Login (top right)
3. Username: `admin` | Password: `admin123`

## Create a Build

1. Click "Create Build"
2. Enter: name, budget, notes
3. Click "Create Build"

## Add Components

1. Click "+ Add Part" on your build
2. Select component from dropdown
3. Set quantity (default 1)
4. Click "Add Part to Build"

## View Budget Status

- Total Budget: Amount allocated
- Used: Total cost of parts
- Remaining: Budget left (red if over)
- % Used: Progress indicator

## Swap or Remove Parts

- **Swap**: Click "Swap" button, select different part
- **Remove**: Click "Remove" to take out a part
- Budget updates automatically

## Manage Builds

From "My Builds" page:
- View Details: See all parts
- Edit Build: Change name, budget, notes
- Delete Build: Remove entire build

## Available Components

23 pre-loaded parts: CPUs, GPUs, RAM, SSDs, PSUs, Cases, Motherboards, Coolers

## Admin Panel

Visit `/admin/` to manage parts and view all data

## Troubleshooting

- Not seeing builds? Log in first
- Budget wrong? Refresh page
- Need new parts? Add them in admin panel
